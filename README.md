# Description
AutoSwiper program using Selenium WebDriver. Scripts written for both Bumble and Tinder. 
Works perfectly for Bumble, but Tinder was partially working due to some issues with XPaths (imo specifically done to intercept this kinda spam)

### Flow
Run script -> Dating app web page opens -> Script waits until user manually logs in and passes 2FA -> Auto Swipe starts
